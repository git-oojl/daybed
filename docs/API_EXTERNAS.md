# APIs externas

Daybed utilizará APIs externas para mejorar el flujo de checkout y entrega.

## API 1: Geocodificación de direcciones

Se usará Nominatim/OpenStreetMap para convertir una dirección de entrega en coordenadas geográficas.

## API 2: Estimación de distancia de entrega

Se usará OpenRouteService para calcular distancia y duración estimada entre la tienda y la dirección del cliente.

## Candidato opcional

Stripe Checkout en modo de prueba puede agregarse como funcionalidad extra si el MVP principal se completa primero.
