# Alcance del proyecto

Daybed es una aplicación web full-stack para una tienda de muebles. El MVP incluye catálogo público, autenticación por roles, carrito, checkout simulado, estimación de entrega mediante APIs externas, gestión de pedidos, inventario y panel administrativo básico.

## Fuera del MVP

No se implementarán pagos reales, logística real, aplicación móvil nativa, chat en vivo, portal de proveedores ni sistema contable avanzado.
